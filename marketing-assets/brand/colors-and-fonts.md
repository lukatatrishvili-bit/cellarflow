# VinOS campaign styling

## Campaign palette

| Role | Hex |
|---|---|
| VinOS burgundy | `#65101A` |
| Deep cellar burgundy | `#17070B` |
| Qvevri gold | `#D5AD5B` |
| Warm cream | `#FBF8F2` |
| Dark text | `#2A1014` |

## Typography used in derived assets

- English: Arial / Arial Bold for broad compatibility.
- Georgian: Segoe UI / Segoe UI Bold for clear Georgian-script rendering.

These are production-safe local choices for the generated assets, not a formal replacement for any future VinOS brand-font license.
